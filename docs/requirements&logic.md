# Requirements

## Functional Requirements

- CRUD for Users.
- Users authentication.
- CRUD for Polls.
- Can vote on Poll.
- Can see your Polls.
- Can see your Votes.
- Can filter polls by category.
- Can close a Poll.

## Non-Functional Requirements

## Business Logic

### Users

- E-mail and username must be uniques.
- Password must be 8 char minimum.

### Polls

- Minimum 2 choices for Polls.
- Can close your own Polls.
